# Scope Work for macOS

Download the latest installer from [Releases](../../releases/latest).

- Apple silicon (M1 or later): `Scope-Work-<version>-arm64.dmg`
- Intel: `Scope-Work-<version>-x64.dmg`

Open the `.dmg`, drag **Scope Work** into Applications. The first time, macOS shows a security warning because the app isn't notarized yet: open **System Settings > Privacy & Security** and click **Open Anyway** (or run `xattr -cr "/Applications/Scope Work.app"` in Terminal, then open it again).

Only installers live here. The source is private.
